# Study Planner

A Java Swing desktop application for organizing study schedules, tracking progress, and preparing for exams efficiently.

## Overview

Study Planner helps students manage their subjects, estimate study workload, and stay on track with upcoming exams. The app automatically generates a personalized study schedule based on:

- subject difficulty
- exam date
- daily study hours
- number of subjects

It includes a dashboard, subject management, schedule tracking, and progress analytics in a clean dark-themed interface.

## Features

- User login and account creation
- Add subjects with difficulty levels and exam dates
- Auto-generate study sessions
- Mark sessions as complete or overdue
- Track daily study hours and overall completion
- View upcoming exams and subject-wise progress
- Modern desktop UI built with Swing
